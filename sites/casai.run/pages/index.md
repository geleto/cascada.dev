# Casai {#hero-title}

**Write the workflow.** Let Cascada handle the concurrency.
{.tagline}

Casai is a TypeScript library for building AI agents and workflows, powered by Cascada and the Vercel AI SDK.
{.development-note}

**Casai is in active development.** APIs and syntax may change. [Feedback](https://github.com/geleto/casai/issues) and contributions are welcome.
{.development-note}

## Why Casai? {#workflows-title}

Connect model calls, tools, and your own APIs with familiar code. Independent operations run together, and each step waits only for the results it needs.
